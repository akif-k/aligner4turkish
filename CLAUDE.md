# Repo-specific instructions for Claude Code

- Do not add a `Co-Authored-By: Claude ...` trailer to commit messages
  in this repository (GitHub parses that trailer and lists Claude in
  the repo's Contributors page — the repo owner does not want that).
  A plain `Claude-Session:` footer line, without the `Co-Authored-By:`
  line, is fine to keep.
- AI assistance is disclosed instead in the "Gelistirme Notu" /
  "Development note" section at the end of README.md / README.en.md —
  keep that section up to date rather than relying on commit trailers.
