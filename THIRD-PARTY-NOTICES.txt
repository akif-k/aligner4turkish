 mms_aligner - THIRD-PARTY NOTICES
===============================================================================
This package runs as a Python application on Linux, macOS, and Windows.
The runtime is provided via a conda environment named "mms_aligner" (see
environment.yml). The model is NOT shipped with this package: it is
downloaded automatically into models/ on first run (see Section 2) and
can be copied/moved to another machine from there (no re-download needed
as long as models/ is copied along with the project).

1) THE mms_aligner CODE IN THIS PACKAGE (mmsaligner.py, config.json,
   syllable_rules.json, run.bat, run.sh)
-------------------------------------------------------------------------------
These files were written specifically for this project and are licensed
under the GNU General Public License v3.0 (GPLv3). See the LICENSE file
(repo root) for the full license text.

The forced-alignment core inside mmsaligner.py (_merge_repeats,
_get_spans, and the general CTC forced-alignment approach) is a direct
port of the algorithm from MahmoudAshraf97/ctc-forced-aligner (see
Section 2 below); the only functional difference is that this port uses
torchaudio.functional.forced_align instead of that project's compiled
C++ extension (forced_align_impl.cpp), so no extra build step is needed.

The syllable-tier engine (_assign_syllable_ids, _build_syllable_tier,
_parse_syllable_types, etc.) is adapted from this author's own sibling
project, ipa_verbatim (also GPLv3), ported from IPA phoneme symbols to
plain Turkish orthographic letters.
